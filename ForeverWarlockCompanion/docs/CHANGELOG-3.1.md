# 3.1.0-preview

La cabecera, paleta azul grisácea, navegación lateral de seis accesos y tres tarjetas
apiladas siguen la referencia del usuario. More agrupa las vistas menos frecuentes;
el estado activo sigue siendo visible. El siguiente objetivo y sus actividades se derivan
del plan del personaje. No se fijan datos de ejemplo ni imágenes ajenas.

Se conservan servicios, objetivos, tracker, perfiles y la selección del tema clásico.
Pruebas de Lua 5.1 y APIs simuladas comprueban regresiones, rutas y datos del dashboard.
La geometría, iconos, fuentes y modelo en el cliente real permanecen sin validar.
