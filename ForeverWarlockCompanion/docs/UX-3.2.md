# Decisiones de UX 3.2

El dashboard usa tarjetas con dos columnas cuando hay espacio y una columna en modo compacto;
la página completa se desplaza. Las tres primeras prioridades se obtienen del servicio de
objetivos, con foco y prioridad existentes, y cada tarjeta abre sus pasos. Los grupos de
actividades representan objetivos pendientes, no recomendaciones optimizadas ni drop rates.

Character Summary, Equipment Progress, Quick Stats y Crafting muestran datos que el cliente
o las tablas existentes proporcionan. Las estadísticas que no se pueden leer muestran un
guion; no hay datos de demostración en el juego. Los cooldowns de Mooncloth son estimaciones
manuales heredadas, etiquetadas, y no indican disponibilidad comprobada.

El panel de objeto separa estado/fuente, estadísticas importadas de guía, comparación,
adquisición y pasos. El tooltip nativo permite consultar el objeto. IDs, metodología y
detalle de comparación pasan a More options. La estimación EP es de puntuación de objeto,
no DPS. No se inventan viajes, jefes, costes ni requisitos para rellenar una checklist.

My Objectives muestra icono, badge de estado, siguiente acción, progreso de pasos y fuente.
El tracker conserva modos y acciones; las filas de pasos muestran instrucciones legibles.
Se reutilizan tarjetas, badge, barra de progreso y empty state del Design System, con ambas
variantes de tema y navegación existentes. La comprobación en juego sigue pendiente: fuentes,
scroll, tooltips, idiomas, escalado, modelos y controles deben revisarse en WoW Forever.
