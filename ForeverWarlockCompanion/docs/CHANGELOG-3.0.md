# Changelog 3.0.0-preview

- Shell con sidebar desplazable, filtros plegables, inicio Dashboard, breadcrumb e historial.
- Forever Design System con tokens, dos temas, tarjetas, estados y barras reutilizables.
- Equipment con alternativas contextuales y adaptación a dos/tres columnas; visor conservado.
- Explorador con iconos, estado/objetivo y filtros avanzados de calidad, propiedad, profesión
  y dungeon. Se conserva orden importado sin ranking.
- Acquisition Objectives persistentes, pasos con evidencia/manualidad, máquina de estados,
  dependencias acíclicas, pasos propios y separación entre prerrequisitos y adquisición final.
- Esquema 3 y copia preV3Backup; perfiles y referencias legacy preservados, migración idempotente.
- Tracker con expansión de pasos, foco, prioridad, modos y posición/tamaño guardados.
- Vistas de dungeon/reputación/actividad por objetivos activos, con navegación a cada objeto.
- Centro de profesiones con búsqueda, enlaces a recetas, overview, historial de cooldowns
  manuales y agregación de materiales para objetivos con costes conocidos.
- Regresiones de Lua 5.1 y caso real de Spellweaver's Turban, más fixtures de materiales.
- Compatibilidad real y revisión visual del cliente pendientes; ver PENDING-3.0.md.
